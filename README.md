One ingredient, one bowl. This entry draws a bowl of steaming ramen with nothing but Python's standard library. The broth, noodles, soft eggs, chashu, narutomaki, green onion, and nori are all plotted pixel by pixel, and the PNG encoder is hand rolled on zlib and struct.

## Run it

```sh
python3 main.py
```

It writes a 1024x1024 PNG to `/output/entry.png`. Set `ENTRY_PNG` to point it somewhere else.
